Scientific Math Keyboard

Klik kotak jawapan, kemudian tekan simbol.

Panel ini berfungsi sebagai scientific math keyboard untuk tulis soalan dan pilihan jawapan, bukan untuk kira automatik. Tekan xⁿ untuk letak kuasa bebas seperti 5, 6, 7 atau x+1. Tekan Pecahan untuk buat pecahan bertingkat. Untuk formula yang sangat panjang, masih boleh guna gambar pilihan jawapan A/B/C/D.

Preview ini hanya untuk semak simbol, pecahan dan equation sebelum admin upload soalan.

Taip soalan atau pilihan jawapan untuk lihat preview.

Optional. Admin boleh letak gambar kecil untuk setiap pilihan jawapan. Di bahagian user, gambar ini akan dipaparkan dalam saiz kecil supaya tidak terlalu besar.

Gambar ini akan muncul sebagai pop up selepas user jawab soalan.
